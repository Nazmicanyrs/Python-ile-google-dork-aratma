Kritik (P1) #secrets
Ortam Değişkenleri (.env) & Şifreler
Veritabanı bağlantıları, JWT secret, AWS erişim anahtarları ve canlı SMTP parolalarını yakalar.
Saldırı Yüzeyi: Doğrudan veritabanı ve bulut altyapısının tam yetkiyle ele geçirilmesi.
filetype:env "DB_PASSWORD" "APP_KEY"
Kritik (P1) #git #vcs
Açık Git Deposu (.git/HEAD & config)
Web kök dizininde unutulmuş ve dışarıdan okunabilen .git sürüm kontrol verilerini tespit eder.
Saldırı Yüzeyi: git-dumper araçlarıyla tüm kaynak kodun, commit'lerin ve gizli anahtarların indirilmesi.
inurl:/.git/HEAD OR inurl:/.git/config
Kritik (P1) #backups
Tam Kaynak Kod & Web Yedekleri
Sunucu bakımı sırasında unutulan backup.tar.gz, site-dump.zip veya database.sql.gz arşivleri.
Saldırı Yüzeyi: Sistemin tüm veritabanı tabloları ve kaynak kodunun tek bağlantıyla sızdırılması.
inurl:backup filetype:tar.gz OR filetype:zip
Yüksek (P2) #recon #arch
İfşa Olmuş .gitignore & Dizin Haritası
Projeye ait gizli dizin isimleri, derleme hedefleri ve harici eklenti yapısını gün yüzüne çıkarır.
Saldırı Yüzeyi: Saldırganın gizli endpoint ve kütüphane bağımlılıklarını haritalandırmasını sağlar.
filetype:gitignore ".env" "node_modules"
Kritik (P1) #pki #ssh
SSH & SSL Private Key Sızıntıları
Sunucuya şifresiz uzaktan erişim sağlayan veya SSL trafiğini çözen özel PEM/KEY anahtarları.
Saldırı Yüzeyi: Doğrudan sunucu root erişimi veya uçtan uca şifrelenmiş trafiğin çözülmesi.
filetype:pem "BEGIN RSA PRIVATE KEY"
Yüksek (P2) #jwt #tokens
Canlı JWT Belirteçleri & Auth Sırları
Base64 encoded eyJhbGciOi başlığıyla başlayan aktif JSON Web Token ve Bearer yetki anahtarları.
Saldırı Yüzeyi: Oturum çalma (Session Hijacking) ve API servisleri arasında yetkisiz işlem yürütme.
"eyJhbGciOi" intext:"Bearer" filetype:json
Kritik (P1) #aws #azure
Açık AWS S3 & Azure Blob Depoları
Yanlış ACL izinleri nedeniyle kamuya açık (public) bırakılmış kurumsal bulut nesne depolama alanları.
Saldırı Yüzeyi: Şirket içi belgelerin, kimlik kopyalarının ve veri ambarı dökümlerinin toplu sızması.
site:s3.amazonaws.com "confidential" OR "backup"
Kritik (P1) #k8s #cloud
Kubernetes Dashboard & API Sunucuları
İnternete doğrudan açık kontrol düzlemi arayüzleri ve kimlik doğrulamasız bırakılan K8s panelleri.
Saldırı Yüzeyi: Kümede pod başlatma, konteyner kaçışı ve tüm altyapıda uzaktan kod çalıştırma (RCE).
intitle:"Dashboard - Kubernetes"
Yüksek (P2) #docker #registry
Açık Docker Registry V2 Kataloğu
Kurum içi özel Docker imajlarının depolandığı ve şifresiz katalog listelemesi sunan registry uçları.
Saldırı Yüzeyi: Özel üretim imajlarının çekilmesi ve katmanlardaki gömülü secret'ların çıkarılması.
inurl:"/v2/_catalog"
Yüksek (P2) #firebase #nosql
Açık Firebase Realtime DB (.json)

Saldırı Yüzeyi: Mobil ve web uygulamalarının tüm kullanıcı veritabanının JSON formatında tek tıkla indirilmesi.
site:firebaseio.com inurl:".json"

Tüm REST endpoint'lerini, veri modellerini, parametre tiplerini sergileyen canlı API arayüzleri.

inurl:"/swagger-ui.html" OR intitle:"Swagger UI"

inurl:"/graphiql" OR intitle:"GraphQL Playground"
