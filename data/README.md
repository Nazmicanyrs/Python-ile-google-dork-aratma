# GHDB data snapshot

- Source: [Exploit-DB / OffSec GHDB](https://www.exploit-db.com/google-hacking-database)
- Official machine-readable archive: [ghdb.xml](https://gitlab.com/exploit-database/exploitdb/-/raw/main/ghdb.xml)
- Retrieved: 2026-10-25
- Snapshot size: 5,578,559 bytes
- Snapshot contents: 7,944 entries in 13 categories; 7,783 distinct query strings (161 repeated query strings).
- Newest `date` value in this snapshot: 2024-08-23. GHDB entry dates and applicability can be stale; this is an archive, not a validation that a query still works.
- The source repository includes a GNU GPL version 2 license; its license text is included as `EXPLOITDB-LICENSE.md`. Review the source repository's current licensing and notices before redistributing.

The catalog UI parses and filters these records locally. It does not submit the entire collection to search engines. A user can select an individual entry to place its query in the search box, and can export the imported catalog as JSON.
